What You Will Learn

Six sessions, one goal: understand how AI agents work, use them safely in your daily work — and build your own agent in Java.

AI or DIE — why now

Disrupted, irrelevant, extinct — or AI-native. Technology, organisation and environment, and the path from digitalisation to agentic AI.

AI, LLMs & agents

How an LLM is made, why it is a “clever parrot”, and what turns it into an agent: memory, RAG, tools and MCP.

Working with AI agents

OpenCode and Claude Code for spec-driven development — and far beyond code: presentations, stock (saham) analysis, research.

Security & agents

An agent can do everything you are allowed to do. Rights, sandboxes, secrets and prompt injection — how to stay in control.

Your own agent with Spring AI

A concrete example, “Warung Digital”: a restaurant assistant built with Spring Boot, Spring AI, NVIDIA models, RAG and tools.

The future of software work

From developer to “product builder”, micro-teams and a new mindset: describe the goal, let agents handle the how.

The Day at a Glance

19, 20 or 21 November 2026 (date to be confirmed) · 09:30 – 17:00 WIB

09:30 – 10:00

Registration, coffee & setup check

Connect to the Wi-Fi and check that OpenCode or Claude Code runs on your laptop. Assistants help if something is missing.

10:00 – 10:45 01

Introduction: AI or DIE

Disrupted. Irrelevant. Extinct. — or AI-native? Lessons from six months of building software with AI agents, the TOE framework (technology, organisation, environment), the maturity model from digitalisation to agentic AI, and how software development evolved: RAD → MDA → low-code → AI agents.

Theory: AI, LLMs and agents

What an LLM is and how it is trained, the road to AGI, the anatomy of an agent (LLM as brain, memory, RAG, tools, MCP), apps vs. services vs. agents, agentic AI with autonomy and multi-step planning — and today’s agent landscape: Claude, OpenCode, Copilot, ChatGPT, Gemini, OpenClaw and more.

11:45 – 12:30 03a

Software development with AI agents

OpenCode and Claude Code in action. Spec-driven development: specify → plan → tasks → implement. Live demo: from a GitHub issue to a finished Spring Boot feature, built autonomously. IDE-centred vs. conversation-centred work.

12:30 – 13:30

Lunch, networking & Dzuhur break

Beyond code: agents for everyday work

Hands-on: let an agent create a presentation, analyse the stock market (saham) from public data, research a topic or automate documents. Pick your challenge and discover what else is possible. Stock analysis is for learning only — not investment advice.

Security and agents: what matters

Agent server vs. agent client: an agent can do everything you are allowed to do — delete data, install software, change systems. Least privilege, sandboxes (Docker, NVIDIA OpenShell), secrets and tokens, prompt injection, human in the loop, and data protection (UU PDP).

15:10 – 15:25

Coffee & Ashar break

Concrete example “Warung Digital”: a restaurant assistant that knows the menu, takes orders and books tables. ChatClient, conversation memory, RAG over menu and FAQ, @Tool methods and MCP — using NVIDIA models from build.nvidia.com (or Claude). Low-code vs. “love-code”.

16:35 – 17:00 06

The future & closing

The “product builder” role and micro-teams, from imperative to descriptive thinking — “Don’t DIE, or at least DIE Hard.” Q&A, certificates and group photo.

Questions

What do I need to prepare?

Your own laptop with an AI agent installed — OpenCode or Claude Code. This is a prerequisite for taking part. For Session 5 you also need JDK 21, Maven, Git and an IDE. Wi-Fi is provided at the venue. You will receive the setup guide after registering.

Do I need to know Java?

Only for Session 5. Sessions 1–4 and 6 need no programming — and in Session 3 the agent does the coding. For Session 5, any object-oriented language background is enough, and a checkpoint branch lets you catch up.

Do I need an API key or a paid AI subscription?

No. Everything runs over the internet with free models: OpenCode brings its own free models (OpenCode Zen), and NVIDIA offers free models at build.nvidia.com — you only need a free account. The Spring AI lab uses the free NVIDIA models. If you have Claude Code, you can use Claude models such as Opus.

Which language is the workshop in?

The workshop is held entirely in Bahasa Indonesia. This website is available in both languages.

Why only 50 seats?

So that every participant gets personal help. With the speaker and five mentors, the ratio is about one mentor per ten participants.
