What You Will Build

One use case all day: “Warung Digital” — a WhatsApp-style assistant for a Jakarta restaurant that knows the menu, takes orders and books tables.

Local LLM with Ollama

Run a model on your own laptop. No cloud bill, no customer data leaving the machine — relevant for UU PDP.

Chat as Code

Spring Boot + LangChain4j @AiService: the bot’s behaviour defined as Java code, with memory per customer.

Knowledge with RAG

Load the menu and FAQ, embed, retrieve. Your agent answers from your business data — not from its imagination.

Tools & guardrails

Check stock, calculate totals, create reservations. Define what the agent may — and may not — do.

MCP integration

The Model Context Protocol, the “USB-C for AI”: connect your agent to external systems and expose your own tools.

AI-assisted engineering

Extend your agent with an AI coding assistant — and learn where its limits are. AI writes, you are responsible.

Questions

What do I need to prepare?

A laptop with at least 8 GB RAM and 15 GB free disk. Before the day, install JDK 21, Maven, Git, an IDE and Ollama with the workshop models. You will receive the setup guide after registering.

Do I need to know Java?

Java helps, but any object-oriented language background is enough to follow. Every lab has a checkpoint branch, so you can always catch up.

Do I need an API key or a paid AI subscription?

No. All labs run on a local model with Ollama. No cloud costs, and your data stays on your laptop.

Which language is the workshop in?

Bahasa Indonesia and English mixed; slides and code are in English.

Why only 30 seats?

So that every participant gets personal help. With the speaker and three mentors, the ratio is about one mentor per eight participants.
